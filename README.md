# Architecture

This section contains small Java projects used to study architecture styles, modular design, and common design patterns. The examples are intentionally simple and focused on clarity rather than production completeness.

## Projects

- api-gateway-sample: a minimal API gateway example built with Spring Boot.
- hexagonal-mapdata: a sample that explores the hexagonal architecture style.
- moodle-sample: a modular sample inspired by Moodle-style domain separation.
- patterns-gof: runnable examples of the classic GoF design patterns.

## Prerequisites

- Java 17+
- Maven 3.8+

Each project has its own README and build instructions. Start with the project that matches the architectural concept you want to review.
