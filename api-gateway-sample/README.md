# API Gateway Sample

This project is a minimal example of an API gateway built with Spring Boot. It demonstrates the core idea of routing requests from a single entry point to downstream services.

## Purpose

The goal is not to provide a production-ready gateway, but to show the basic flow and responsibilities of an API gateway in a simple and easy-to-follow form.

## What it demonstrates

- request routing
- simple service orchestration
- a lightweight gateway structure

## Technology stack

- Java 17+
- Spring Boot
- Maven
